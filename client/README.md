# Mills client

React + TypeScript (Vite) single-page app. See [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md)
for the project layout and key decisions.

## Scripts

- `npm run dev` — start the dev server at `http://localhost:5173/Mills/`
- `npm run build` — type-check and build for production
- `npm run typecheck` — `tsc --noEmit`
- `npm run lint` — ESLint
- `npm test` — Vitest
